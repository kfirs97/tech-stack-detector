# Tech Stack Detector — Wappalyzer & BuiltWith Alternative

Detects the technologies behind websites (CMS, e-commerce platform, frameworks, analytics, CDN, hosting… 7,600+ technologies) using the community [webappanalyzer](https://github.com/enthec/webappanalyzer) fingerprints. HTTP-only, fast, bulk-ready.

**▶ Run it on Apify (no setup, $0.01 per website, failed sites free): https://apify.com/kfirs/tech-stack-detector**

Usage, input/output format and API examples: [`.actor/README.md`](.actor/README.md).
