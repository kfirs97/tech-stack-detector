# Tech Stack Detector

Apify Actor that detects the technologies behind websites (CMS, frameworks, analytics, CDN, e-commerce…) using the community [webappanalyzer](https://github.com/enthec/webappanalyzer) fingerprints.

Run it on Apify: https://apify.com/ (search "Tech Stack Detector — Wappalyzer Alternative"). See `.actor/README.md` for usage.
